# WaveQTL-2D

**WaveQTL-2D** is a lightweight prototype extending [WaveQTL (Shim & Stephens, 2015)](https://github.com/heejungshim/WaveQTL) to test for differences between two conditions across multiple samples of **2D symmetric matrices** (e.g. pairwise correlation, interaction, or co-occurrence maps).
